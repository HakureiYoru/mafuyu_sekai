# 凤小梦大战朝比奈真冬

**v5.1.1 · 更大的气泡与备用血药**

以 Project Sekai 的凤笑梦与朝比奈真冬为主题的整蛊向同人弹幕游戏。笑梦只想大喊 Wonderhoy，阴暗的真冬只想让她闭嘴。笑梦越喊越开心，真冬从压抑、冷漠走向狂躁，用弹幕把声音压回去。台词和道具采用原创黑化整蛊演绎；操作与伤害说明保持直白。

面向 PC 键鼠。每局从 Lv1 出发，在连续战役中面对十一种混合敌人与五位首领，通过六槽模块、两级强化和组合进化形成自己的打法。普通难度设计目标为 10–15 分钟，选卡时间不计入战斗时间。

笑梦与真冬现在以全身 Q 版小人在战场两侧接话：八张独立姿态、24 组短对话，保留上一句和表情动作。侧边空间不足时自动切换底部双头像；暂停、选强化和减弱动态均生效。新素材合计约 477 KiB，不覆盖战场、也不改变五张原始贴图。

## 运行与构建

需要 Node.js 22.13 或以上。

```sh
npm ci
npm run dev
```

开发地址默认 http://127.0.0.1:5173 。

```sh
npm run build
npm run preview
```

将完整 `dist/` 交给静态 HTTP 服务；`npm start` 同样启动构建预览。相对 base 支持子目录，旧 `/dx.html` 保留查询参数并跳回首页。需要硬件加速及 WebGL。

Vercel 由 `vercel.json` 固定使用 Vite、`npm ci --include=dev`、`npm run build` 和输出目录 `dist`。Root Directory 为仓库根目录。发布时核对同一提交的构建状态与线上流程。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动／瞄准 | WASD／鼠标 |
| 连续射击 | 按住左键 |
| 精准慢移 | Shift，180 单位／秒，强化显示核心 |
| 冲刺 | R／右键，移动方向优先，静止时朝准星 |
| 贯穿炮 | 冲刺结束后 0.85 秒内的下一次左键射击；按住自动衔接 |
| 炸弹 | Space，按下触发一次 |
| 暂停／继续 | Esc；失焦自动暂停 |
| 强化选择 | 点击或 1／2／3 |

Q、E 不再绑定技能。设置支持其余操作改键，Esc 与选卡 1／2／3 保留专用。子机自动索敌，轨道护刃追随主炮实际命中的目标。

普通移速 300；敌弹、激光与范围攻击使用半径 7 的核心判定，撞怪、地雷和边界使用半径 18。起始生命 5、炸弹 3，炸弹最多 5 枚，满额每枚转 30 XP。炸弹保留附近 750×750 伤害、全场清弹和 2 秒无敌。

冲刺冷却 2.6 秒、持续 0.18 秒；贯穿炮伤害 40、宽 88、长 2400，清除走廊中的敌弹，过热时仍可通过左键释放。强化窗口不能叠加或储存。主炮只管理热量，持续开火约四秒过热，停火恢复，不使用弹药。

困难普通怪生命 ×1.5、移动 ×1.3、弹速 ×1.28、受击伤害 2，首领生命 ×1.35；判定大小不随难度改变。

## 连续战役

常规推进共 360 秒，首领战暂停推进计时，但战斗和冷却正常运行。依次在推进 90／180／240／300／360 秒挑战 **ECHO → PALISADE → MAFUYU → REPRISE → LACUNA**，必须击败才能继续。

MAFUYU 与 LACUNA 各保留六张独立符卡、固定 1600×900 战场和画布外 HUD。击败 MAFUYU 后返回世界继续战斗，只有击败 LACUNA 才通关。其他首领保留有限增援。普通世界为 4000×4000，逻辑视野固定 1600×900。

十一种敌人逐步引入并混编，不再按季别分池。保留弱点打断、镜盾护卫、贯穿炮破盾、重弹误伤、地雷和碎核爆破等战术关系。生命按预定推进时间增长，不根据玩家装备动态抬高。

每只普通敌人保证提供 10 XP，功能道具独立掉落。Lv2–10 累计需要 3970 XP；两档受伤不掉级，只扣当前升级需求 25% 的 XP。推进 45 秒及击败前两位首领提供子机，上限三台，重复转为 60 XP。前四位首领补 2 HP、1 炸弹、热量与冲刺库存，并提供一次强化。

黑洞在剧情后期和无尽中持续掉落：每只普通敌人有 1% 概率，连续 80 只未掉落时保底一次；掉落后重新计数，首领战与过关不重置进度。血药拾取后每份回复 1 HP，多余数量存入生命条下的备用库存，受伤时自动补血，不再停留在玩家身边。库存不会免除受伤的经验损失，也不会复活；继续无尽保留，重新开局清空。

## 构筑

24 个模块均可升至 II 级，最多六槽。Lv2–10 和前四位首领提供最多十三次三选一，每局两次重抽。选卡冻结当前战场，选择结束后继续原来的敌人、弹幕与掉落，不因升级清场。

| 分支 | 模块 |
| --- | --- |
| 主炮 | 贯通线圈、双联翼炮、精密校准、碎晶弹头、导电追踪、分光棱镜、反跳弹芯、尾迹火花 |
| 子机 | 追迹矩阵、共振集火、离子束缚、分工索敌、防卫拦截、轨道护刃、交叉阵位、回旋机翼 |
| 机动资源 | 双蓄推进、排热喷口、冷凝弹仓、擦弹回收、复苏应答、寻物脉冲、制动场、余迹脉冲 |

六种进化为针轨贯阵、回旋花火、分叉电网、三角围攻、巡猎回旋和残响疾行。指定主模块 II＋搭配模块 I 后，可在首领奖励中选择进化，每局最多两种，原槽替换、不腾槽。具体条件和效果在选卡与暂停界面查看。

Lv10 后每 600 XP 获得 +5% 共鸣伤害，最多四级。追加攻击不能递归触发模块。继续无尽保留构筑及已消耗的复苏等状态，采用混合敌池和首领轮换，不产生永久属性收益。

## 存档

每局固定 Lv1、0 XP、无模块与子机，不再继承旧通关属性。刷新或失败后重新开始完整战役。

`mafuyu-sekai:profile:v2` 保存新规则下的成绩，按普通／困难、剧情／无尽分别记录，带备份及跨标签页同步。旧分季存档和最高分只读保留为历史，不转换成新成绩。存储被拒绝时本页面仍可继续，并显示“未保存到浏览器”。原有音量、画质和其他有效键位保留。

## 架构与验证

Vite + TypeScript + React + PixiJS 8／WebGL，唯一主循环使用 60Hz 固定模拟和渲染插值。React 只订阅 HUD 与流程状态；战役、模块、存档、输入、模拟、渲染和音频分开管理。

```sh
npm run check
npx playwright install chromium
npm run test:e2e
npm run benchmark
node scripts/validate-danmaku.mjs
node scripts/balance-v5.mjs
npm run test:soak
```

`check` 包含类型、lint、模拟测试、原始资源哈希及生产构建。浏览器流程覆盖菜单、原地选卡、首领流程、存档、暂停恢复、窗口适配和连续重开。

`benchmark` 保留 180 敌人＋70 地雷＋1200 子弹＋900 粒子的固定压力场景；弹幕脚本另测密集符卡与构筑连锁。`test:soak` 默认普通难度真实 30 分钟无尽，可用 `MAFUYU_SOAK_DIFFICULTY` 与 `MAFUYU_SOAK_SECONDS` 切换。无人值守无敌测试只验证稳定性。

平衡脚本将正常生命与无敌输出诊断分开，记录实际候选、首领入口等级、耗时、伤害来源及资源消耗。自动控制不等同于真人体验。`node scripts/verify-deployment.mjs` 验证线上版本、新战役完成保存和刷新后的 Lv1 开局；`MAFUYU_DEPLOYMENT_URL` 可指定部署地址。

详见 [v5.0 战役设计](docs/design-v5.0.md)、[v5.1 通讯设计](docs/design-v5.1.md)、[当前文案规范](docs/copy-v5.0.2.md)、[小人素材与生成记录](docs/asset-sources-v5.1.md) 和 [本次验证](docs/validation/v5.1.1.md)。RTX 3060 Laptop 数据单列，核显目标仍需对应设备实测。
