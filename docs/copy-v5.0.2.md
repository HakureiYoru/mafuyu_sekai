# v5.0.2 文案：凤小梦大战朝比奈真冬

标题、浏览器标签、加载页、画布无障碍标签和项目首页统一使用用户指定的「凤小梦大战朝比奈真冬」。正文角色名使用凤笑梦、朝比奈真冬。

## 用户确定的方向

真冬恢复早期版本阴暗、黑化的基调：空洞、寒冷、拒绝接近、强压情绪，随后被 Wonderhoy 刺激到狂躁爆发。笑梦说话简单，一句一个意思，使用短促惊叹、拟声、害怕和反复大喊 Wonderhoy。笑点来自两人的强烈反差；真冬认真而阴暗，笑梦不理解为什么喊了大家还不开心。

不再使用上一版“礼貌送客”“场务吐槽”“园区营业管理”等方向，不给笑梦安排成熟机智的长段反讽。早期真冬可以用仍在微笑的冷硬外壳说话；首领和后期符卡更明显失控，不能全程只剩同一句闭嘴。

## 调研依据与本作演绎

- [真冬官方角色页](https://pjsekai.sega.jp/character/unite05/mafuyu/index.html)：受信赖的优等生是外在形象，内在有长期压抑、失去自我与寻求容身之处的一面。写作取其表里落差、空洞和自我感缺失，不再只照外部礼貌形象写。
- [笑梦官方角色页](https://pjsekai.sega.jp/character/unite04/emu/index.html)：天真开朗、想到就行动，希望让大家笑起来；口头禅是 Wonderhoy。台词使用直接感叹和重复，减少复杂词汇。
- [25时官方介绍](https://pjsekai.sega.jp/character/unite05/index.html)：空白 SEKAI 的寂静、微光和无机质氛围支持本作的冷暗场景意象。
- [两人互动的日文剧情整理](https://note.com/usa_pjsekai/n/nd4c7663f2fa9) 是二级剧情转录，标注《走れ！体育祭～実行委員は大忙し～》第4话和学校区域会话：笑梦察觉真冬笑容的异常而害怕，同时还想用 Wonderhoy 让她开心。这作为关系梗的辅助依据，不将转录当作官方逐字原稿。
- [笑梦官方自我介绍入口](https://www.youtube.com/watch?v=UZ5danfxYLQ)、[真冬官方自我介绍入口](https://www.youtube.com/watch?v=tIqXODldSzk)。后者由 [SEGA 新闻稿](https://prtimes.jp/main/html/rd/p/000003235.000005397.html) 列出。本轮未取得完整视频内容，不声称已分析整段声线或逐字字幕。

“狂躁黑化、用弹幕让笑梦闭嘴”是用户指定的整蛊向二创放大。游戏台词为原创，不把战斗中的极端行为当作官方性格结论。

## 显示与功能

菜单保持简单，一行对照：“笑梦：Wonderhoy！！　真冬：……闭嘴。”。标题中的“凤小梦”保留原字，不自动改名。

首领、阶段、符卡恢复空白、噤声、寒光、回声、压抑崩裂等意象。模块仍显示清楚的功能名、精确数值及独立风味短句。控件、伤害判定、资源状态、预告、存档失败和重试说明继续直说，不让玩家靠梗猜操作。

保持两行通讯、正确角色名与头像、有限队列、暂停冻结和重开清空。Wonderhoy 的真冬回应服从受伤、首领和结算等优先事件；不改变游戏攻击、难度数值或模拟速度。
