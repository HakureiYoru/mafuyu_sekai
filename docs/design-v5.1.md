# v5.1 双人 Q 版气泡通讯

## 目标

笑梦简单地喊 Wonderhoy，真冬由空洞冷漠逐渐烦躁、阴暗和暴怒。完整 Q 版人物与短气泡表现二人的反差，仍遵循 [v5.0.2 文案方向](copy-v5.0.2.md)。不改变战斗数值、敌人 AI、输入绑定，不添加配音。

## 画面

- 笑梦左、真冬右，正常小人高 104px、气泡宽 148px；紧凑侧边档小人 68px、气泡 96px。左右留白容器独立裁剪，动作和阴影也不能越进战场。
- 依据实际画布边界，最窄侧留白不足 104px 时，切为底栏双头像和当前气泡；不改变原有 16:9 视野与 HUD 高度。六个模块槽保留。
- 当前发言亮显，同组上一相反角色的完整句暗显；最多两个气泡，无无限历史。静默期间小人保留，收起通讯则隐藏对话区。
- 八张新绘透明 WebP 姿态，非阻塞预加载，失败回退原头像。CSS 布局和 Web Animations API 仅在消息 ID 改变时触发短跳、受惊、侧头或震颤，不新建计时循环。
- 暂停／选强化冻结动画；减弱动态（游戏设置或操作系统偏好）显示全文和静态人物，低画质取消装饰符号。展开时不补播收起期间的动作。

## 通讯状态

24 组 53 句原创短对话：开局 2、Wonderhoy 6、受伤 3、治疗 2、强化 3、五首领各 1、失败／通关／无尽各 1；每句模板不超过 24 字符，分数占位符按真实分数替换。旧 223 条单句数据保留作战斗补充。

新增 `CommsMessage.conversationId / fullText / mood / gesture` 与 `HudSnapshot.commsPrevious`。表情由完整消息的元数据决定；React 不读取模拟实体，也不从逐字文本猜表情。

打字 35 字符／秒，句长为 `max(1.8, fullText.length / 35 + 1.4)` 秒。所有换句使用唯一模拟时钟；本组余句最多两条，普通短对话全局至少相隔 12 秒，忙碌时丢弃过时闲聊。候选按组轮换，优先看完各条再重复。

同一批事件优先结算终局；其后首领入口、符卡、受伤、首领击破、首领低血量与升级按重要程度处理。重要事件清除被打断的后续句。首领预告和真正入场去重；已有成组回应的 Wonderhoy 不再追加旧自动回复。

终局已停止模拟，因此失败／通关直接显示该组最后两句全文，重复事件不产生新消息。回菜单和重开清空当前对话；继续无尽通过 `startEndless()` 显式替换终局内容，不恢复旧闲聊。
