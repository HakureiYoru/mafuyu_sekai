## 机制与视觉

- 浏览器无关触屏测试覆盖死区和幅度、独立多指抬起、cancel/lostcapture、稳定目标、碰撞边缘距离、部件优先、离屏/死亡/不可伤、停火偏好、85/35 迟滞和过热贯穿炮。

## 复现

```sh
npm run typecheck
npm run lint
npm run test
npx vitest run --maxWorkers=2 --testTimeout=15000
npm run test:assets
npm run build
npx playwright test
npx playwright test --config playwright.mobile.config.ts
npx playwright test --config playwright.mobile.config.ts -g "touch layout"
npm run test:mobile-soak
```

`MAFUYU_MOBILE_SOAK_SECONDS=1800` 才是正式 30 分钟验收；短跑仅用于校验夹具。`MAFUYU_MOBILE_SOAK_FPS=60` 使用移动默认渲染频率。运行报告包含独显信息、实际渲染帧率、模拟步数、选卡停顿、对象池和回收后内存。诊断无敌仅用于运行稳定性，不能当作正常通关或难度证据。

线上触屏流程复用 `scripts/verify-deployment.mjs`，设置 `MAFUYU_DEPLOYMENT_TOUCH=1`：真实 DOM 摇杆和选卡触摸，五精英阻挡、五首领和十二张卡依次通过真实伤害/结算路径，存档刷新及 Lv1 重开；计时和击杀由诊断接口加速，不代表自然通关成绩。产物入口 SHA-256 与本地构建比对后再记录部署提交。
