## 构建、机制与浏览器

完整 `npm run check` 通过：TypeScript、ESLint、25 个文件中的 457 项单元测试、资源哈希和 Vite 生产构建。五张原始 PNG 与旧版基准完全一致，八份既有附加素材及来源记录也通过校验。[最终源文件及构建指纹](build-v5.0.0.json) 记录待发布内容；其中 baseCommit 是父版本，不冒充 v5 发布提交。

机制覆盖自动衔接贯穿炮、窗口过期/过热/不叠加、Q/E 默认无行为、7/18 判定、碰撞扫掠、基础与次生伤害、六槽/两阶/两次进化、十三次奖励队列/重抽/旧选项拒绝、模块冷却与消耗状态、首领清场与升级原位暂停分离。30/60/120/144Hz 呈现日程验证固定步长模拟结果一致。新增模块在真实模拟中验证伤害及命中次数，不只检查配置值。

五首领依次阻挡推进，十二张符卡逐一击破；MAFUYU 之后解除竞技场继续，只有 LACUNA 发出通关。首领奖励、满额炸弹转换、遗留掉落和不重复结算有专门回归。固定种子的普通/困难符卡路线共 36 项回归通过，包括弹层叠加、角落和近身，不扩大永久安全区域。

35 项生产浏览器全量通过，覆盖四种窗口、低画质危险预告、20 次重开、热量/冲刺/选卡/失焦、五首领真实完成事件、跨标签页合并、旧历史只读、备份与存储拒绝。复核发现失败页漏显示存储错误，已仅增加 `SaveNotice`；其追加用例与最终构建结果记录如下。

追加的真实范围攻击致死＋拒绝 `localStorage.setItem` 用例在最终构建 `index-BMerQEtE.js` 通过：失败页显示“未保存到浏览器”，再次挑战仍 Lv1，会话分数 7654 保留。浏览器合计 36 项通过，是此前 35 项完整运行加此次单项回归，不声称 36 项在同一次命令中运行。修复后全局 lint、类型检查及生产构建再次通过；模拟代码未改。

## 独显性能

1080p 窗口、中画质，实际画布 1628×916；持续 180 名非地雷敌人＋70 地雷＋1200 子弹＋900 粒子，预热 3 秒、采样 30 秒。独占浏览器压力测量结果：

| 指标 | RTX 3060 Laptop |
| --- | ---: |
| 平均 RAF FPS | 178.57 |
| P50 / P95 / P99 | 5.6 / 5.7 / 5.8 ms |
| 最大帧间隔 | 11.3 ms |
| 页面错误 | 0 |

[逐秒记录](performance-v5.0.0.json) 保留实体数和渲染资源数量。固定场景保持负载，不能单独用来推断真实 AI 压力或输入延迟。

五个困难密集符卡及一个六槽 II 级/双进化连锁场景分别预热 3 秒、采样 24 秒：[完整记录](danmaku-v5.0.0.json)。六组 P95/P99 均约 5.7ms，每组实际模拟推进 24 秒，采样最高 142 颗子弹、41 张纹理；模块场景保持六槽及两次进化，没有中途进入选卡造成虚假空载结果。页面错误为零，资源均在上限内。

上述性能测试在最后一行失败页 `SaveNotice` 修复之前运行；战斗、渲染、资源管理源码未因该修复改变，后续真实 30 分钟无尽使用修复后的最终构建。

## 实际模拟平衡矩阵

三种种子 × 普通/困难 × 主炮/子机/机动/混合偏好 × 正常生命/无敌输出诊断，共 48 项。每局真实 Lv1 开始，使用实际掉落、实际候选和原伤害；不强塞模块、补等级或改敌人生命。控制器每 100ms 决策，对可见危险保留 200ms 识别延迟；只在标记为 DPS 的对照中启用无敌。源文件哈希在运行前后校验。

[修正后原始记录](balance-v5.0.0.json) 与 [修正前控制器基线](balance-v5.0.0-controller-baseline.json) 同时保留。基线困难 ECHO 段 51 次受伤中 40 次来自激光、11 次接触，12 个样本均未使用炸弹；控制器只看 `WorldState.hazards`，漏掉 ECHO 直接绘制和判伤的激光、冲刺预告。配对修正仅让验证控制器识别屏内已显示的相同几何，并排除当前无法使用的生命/冷却道具；没有修改游戏、生命、伤害、AI 或炸弹策略。

精确瞄准、合成路径预测与三种种子不能等同真人通过率。偏好并不保证选到对应模块，同一种子的场景和早期构筑可能重合，因此不将十二次结果视为十二个独立随机样本。控制器没有专门绕盾或利用全部弱点的策略；目标入口等级与实际偏差均保留，不用理论满命中 DPS 或无敌样本代替生存测试。

## 真实 30 分钟无尽

[完整记录](soak-v5.0.0.json)。1920×1080、中画质、普通无尽、Lv10/三子机，使用前述六槽 II 级/双进化上限夹具。每 100ms 发送真实 DOM 键鼠事件，未追加模拟步或加速时间；无人值守角色无敌，因此只用于稳定性检查。

真实时间 **1800.136 秒**，模拟 **1800.117 秒 / 108007 tick**，62 次资源采样，到达无尽第 36 波。触发 548 次冲刺、观察到 547 次左键自动衔接贯穿炮；观察到子机弹，构筑等级和进化全程保留，没有意外状态切换。最终入口文件哈希与运行开始时一致。

采样最高 179 敌人、74 子弹、105 掉落、347 粒子、57 纹理、11 声音声部；采样地雷数为零，地雷负载由前述 70 地雷压力场景及机制测试另行覆盖。原始 JS 堆最高 43.95MiB，GC 后基线 7.27MiB、结束 18.61MiB，随初始场景变为满敌人场景增长，未超过保留内存阈值。末次监听器 208 个，接近基线 210；临时数量超过基线＋100 时按原阈值进行 GC 复查，前后数据均保留，未放宽阈值隐藏增长。

页面错误、控制台错误、资源违规均为零。私有对象池总分配数未暴露，活动实体、纹理和保留堆是可观察代理，不声称检查了池内部每次分配。

结束后重开恢复剧情第一段，仅一个活动 RAF/画布；子机、光束、危险区归零。返回菜单后 RAF 停止，250ms 后 tick 仍为零。独立的 20 次重开与新局 Lv1 浏览器回归也通过。该 30 分钟测试未与其他浏览器/GPU 压力程序并行。

## 发布

发布流程使用 `scripts/verify-deployment.mjs` 在独立浏览器中比对线上入口与本地已测构建的 SHA-256，再检查五首领、十二张卡的真实完成事件、强化选择、通关保存、刷新与 Lv1 重开。关卡接近时间和伤害由调试夹具加速，不算真人试玩，也不修改用户浏览器存档。推送后的同提交 Vercel 状态及线上结果另行追加。
