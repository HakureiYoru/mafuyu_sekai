## 平衡方法

`scripts/balance-v6.mjs` 从真实 Lv1 开局，通过真实候选选择及真实掉落收集；十个种子、主炮 / 子机 / 机动 / 混合偏好、两档难度分别记录。普通生命与标注为 DPS 诊断无敌的样本分开。日志包括首领入口等级 / 构筑、实际命中 DPS / 核心利用、击杀用时、受伤、治疗储备与炸弹，以及每十秒出生 / 敌弹释放 / 首攻比例。各报告包含运行时源文件 SHA-256。

中间诊断报告保留在本机 `.tmp/v6-research`，不作为最终稳定源码矩阵。正式完整原始记录采用 JSON gzip 压缩并附可读汇总，可由脚本重新生成。普通模式有效战斗目标 10–15 分钟；选卡暂停用时另计。自动控制器精确瞄准与预测不等于真人熟练度，真人主观学习难度仍需试玩反馈。

最终稳定源码 80 / 80 局均通关。普通 40 局为 707.483–866.667 秒（11:47–14:27），中位 799.950 秒；困难为 812.700–1149.567 秒，中位 1004.883 秒。普通实际强化 21–25 次、中位 23，低于 24–30 的设计目标；前 18 次升级 / 精英 / 主首领奖励没有漏发，差异来自后期实际 XP 收益及受伤扣 XP。保留明确的每 600 XP 规则，不把目标当作保底宣传。

首领耗时也不一概宣称达标：普通 PALISADE / REPRISE / LACUNA 中位为 65.7 / 70.1 / 156.1 秒，超过初始分场目标；整局仍在 10–15 分钟内。控制器不会根据近程模块优化站位或主动规划全部核心窗口，因此数据用于定位首版待试玩项目，不作为最优 DPS 或真人难度结论。晚段普通怪首攻比例从前段约 9.5% 升至 17.5%，十秒采样敌弹中位从 0 升至 10；已承诺攻击因容量不足被拒绝为 0。完整难度 / 构筑 / 分首领表格见 [平衡记录](balance-v6.0.0.md) 与 [精简汇总](balance-v6.0.0-summary.json)。

## 性能、长时运行与素材

固定压力：180 普通敌人 + 70 地雷 + 1200 子弹 + 900 装饰粒子。新增全 36 模块 / 18 进化在 V 层与 100 层的编队战、24 场固定站位符卡扫描和浏览器负载测试。全构筑及数字补测报告记录产物 SHA-256，旧固定压力报告由本记录注明构建标识，不把 CPU 加速模拟当浏览器帧率。

RTX 3060 Laptop、1920×1080 窗口、中画质下，`index-DPjiPZWn` 的固定压力、V 层全构筑、100 层全构筑、扫描中敌弹采样最多的符卡四场 P95 / P99 均约 5.7 / 5.7 ms。战斗画布实际约 1579×888，其余窗口用于 HUD 与通讯。全构筑场的模块装置采样峰值 22 / 35，敌我弹池分别计量；该符卡场使用普通 LACUNA 第一卡，45 秒正常模拟、不射击、不带自动子机，峰值 240 敌弹且首领 HP 始终不变。此前只测终曲低估负载的中间结果不作为本轮扫描选出的高密度场景。见 [固定压力](performance-v6.0.0.json)、[全构筑与扫描高密度符卡](performance-builds-v6.0.0.json)、[24 场扫描](spell-density-v6.0.0.json)。

最终 `index-D-qbO7oo` 只替换数字浮字为有限图集，并修改一条更新日志措辞；全 36 模块 100 层 + 18 进化的 30 秒复测仍为 P95 / P99 约 5.7 / 5.7 ms，峰值 83 敌人 / 59 敌弹 / 115 我方弹 / 28 模块装置。见 [数字绘制补测](performance-text-v6.0.0.json)。

30 分钟真实浏览器无尽使用 DOM 操作，真实选卡暂停，不追加模拟步进。记录独立弹池、模块装置、DOM、监听器、纹理、声部及每五分钟回收后的堆；退出后验证重开和菜单只有一个画布、一个主循环。无人值守运行开启玩家诊断无敌，仅验证稳定性。

第一次长测在 19.5 分钟主动停止作为诊断记录：没有运行预算违规，但源码审查与独立复现证明 Pixi Canvas Text 会为不同数字遗留空缓存键。修复为公共 BitmapFont API 安装的有限字符图集，数字浮字与混合数字提示使用 BitmapText，固定中文仍用 Text，保持 36 标签池与合并行为。未修改依赖包或私有缓存。旧记录位于本机 `.tmp/v6-research/soak-before-bitmap.json`，不能当作完成 30 分钟。原理、边界及截图见 [文字缓存验证](text-cache-v6.0.0.md)；最终长测重新从零计时。

最终长测通过：墙钟 1800.075 秒、实际模拟 1797.167 秒，62 组资源采样，60 次真实 DOM 强化选择，构筑由 180 层增长至 240 层并保留全部 18 进化。浏览器错误、控制台错误和预算违规均为 0；预热后回收堆保持约 15–18.3 MiB，最终 17.54 MiB。退出与重开确认单画布、战斗唯一 RAF，菜单 RAF 停止且 tick 不再推进。完整数据见 [30 分钟无尽](soak-v6.0.0.json)，[开始截图](v6.0.0-soak-start.png) / [结束截图](v6.0.0-soak-end.png)。

五张原始 PNG、八项支援素材、八张小人全部按原来源记录校验。Windows `core.autocrlf` 会改写 SVG 换行，新增 `.gitattributes` 固定这些已记录哈希的 SVG 为 LF；文件内容恢复为原仓库字节，未改贴图或更新哈希来绕过验证。小人合计 488016 字节。
