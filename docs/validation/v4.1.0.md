## 真实30分钟无尽

[完整记录](soak-v4.1.0.json)。第二季普通、Lv8/三子机/七模块开局，真实DOM键鼠事件每100毫秒驱动，无额外模拟步或时间加速。无人值守角色无敌，此项只验证稳定性；不作为真人难度证据。

真实时间1800.044秒、模拟1800.033秒/108002tick，61次资源采样通过，到达无尽第38波。触发548次冲刺、547次Q按下、232次E指令，观察到1629条主/副光束；中途没有异常状态切换。

采样最高40敌人、90子弹、243粒子、49纹理、9声音声部。原始JS堆最高37.63MiB；五分钟GC后约13.11MiB，结束后14.61MiB，未超过保留内存检查阈值。临时DOM/监听器超过基线时按原阈值复查GC后数量，并保留前后样本；结束后210个监听器，没有提高阈值来隐藏增长。页面错误、控制台错误、资源违规均为零。私有对象池的总分配量未暴露，报告使用活动对象、纹理与保留堆作为可观察指标，不声称测量了池内部。

最终重开只有一个画布和一个活动运行时，子机/光束/危险归零；返回菜单后RAF停止，250毫秒后tick仍为0。该长时测试部分时段与低优先级平衡矩阵、本地发布流程验证并行，不作为独占帧时间测量；前面的固定压力和密集场景单独测量。
