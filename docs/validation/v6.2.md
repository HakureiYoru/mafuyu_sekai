# v6.2.0 验证记录

环境：2026-09-20，Windows、Node 22.17、RTX 3060 Laptop，Chromium D3D11。没有接入 iPhone 或安卓真机；所有手机流程是桌面触屏仿真，不作为手机 60 FPS 或核显验收。

本地检查：类型、lint、40 文件 / 768 单元测试、原图哈希及生产构建通过。桌面流程 59 通过 / 1 条设备条件跳过，v6.2 新增流程 3 通过；移动流程 25 通过 / 3 条 WebKit 缺少 AudioContext 或 CDP 触点能力而跳过。Retina 冒烟 10 通过 / 1 条设备条件跳过 / 1 条 Windows WebKit 画布像素失败，详情如下。

## 玩法

两档十二卡的输入路线测试各运行 80 秒，覆盖普通起点、四角、近身六个起点。规划器对已出现预警延迟 200ms 后响应，使用正常移动、慢移、冷却允许的冲刺，不使用炸弹或临时补血。移动路线全部零伤，预判代价要求额外 10 单位余量；完整七墙慢移测试实测通过时额外余量至少 20。每卡至少两次完整身体动作，检查首次时间、起手间隔、预警和收招时间，以及身体动作期间不发新弹幕。站桩、固定绕圈、旧固定方向对照不能稳定解完全部六卡。

延长测试暴露困难交错绝域在后续循环的横纵叠墙问题；修正为每两轮同轴后换轴，旧列车离开后再开始垂直列车。这属于攻击编排变化，未改变首领生命、单弹伤害或弹速。以上自动路线证明所测起点有可行解，不能代替真人对可读性和难度的判断。

固定 30 / 60 / 144Hz 的原有时钟回归保留，模拟、十二卡逐卡击破、20 次重开、全 36 模块与 18 进化、四种桌面和手机小屏布局均保留测试。新图片未改动原五张 PNG。

## 排行榜

`scripts/verify-leaderboard.mjs` 对真实免费 Redis 的隔离预览空间验证：

- 四个并发同局提交只产生一条最佳成绩；低分不覆盖高分与首次时间。
- 更高分和改名，同名的两个浏览器身份独立；同分后取得者排后。
- 身份 Cookie 随刷新保留；八个榜隔离、返回本人排名。
- 非法分数、昵称、时长、其他身份盗用凭证被拒绝；触发频率限制。
- 浏览器额外验证真实开局→主动结束→留名，失败提示与刷新后手动重试、手机竖屏榜单。
- 单元测试验证剧情冻结后继续无尽独立结算、触屏归类、凭证延迟、重复结算、测试局排除、签名过期。

测试脚本先检查服务器的 preview 环境标记，拒绝往正式榜提交诊断成绩。详见 `v6.2-leaderboard.json`。账号已完成 Vercel 登录和 Marketplace 条款，免费 `mafuyu-arcade` 已关联项目，自动升付费关闭。

## 视觉与性能

保留旧版 7b75fca 的静态构建，在同机依次对比相同压力场景，1920×1080、中画质，预热 3 秒、采样 15 秒。全构筑场景为真实战斗中的全部模块 20 层；诊断无敌与高首领 HP 用于维持负载，不用于平衡判断。

| 场景 | 旧 P95 / P99 ms | 新 P95 / P99 ms | 旧 / 新 draw calls P95 |
| --- | --- | --- | --- |
| 180 敌人、70 雷、1200 弹、900 粒子 | 16.8 / 16.8 | 16.7 / 16.8 | 12 / 12 |
| 全模块与进化 | 16.7 / 16.8 | 16.7 / 16.8 | 15 / 21 |
| LACUNA 终曲 | 16.7 / 16.8 | 16.7 / 16.8 | 14 / 14 |

无浏览器异常。全构筑新版本峰值为 21 buffer、28 texture、4 program；样本限于这些场景，VSync 下相同帧时间不证明剩余 GPU 余量。原始资源采样、draw calls 和 GPU 标识见 `v6.2-performance-comparison.json`。截图在 `v6.2/`；包含贯穿炮束芯、可见弹墙缺口和预览测试榜。

Windows WebKit 的高 DPR 像素检查出现黑画布；同环境的旧版冻结构建也复现，且没有 JS 异常。不能将此项标为通过，更不能因此声称 iPhone 画面已实测。Linux CI 的 WebKit 检查及真实设备结果需分别记录。Chromium 画面检查与新 Shader 流程通过。
