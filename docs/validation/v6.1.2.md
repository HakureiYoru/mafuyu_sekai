# v6.1.2 组合指引与精英收招调整

强化选择新增每张卡对应的进化方向、选择后欠缺模块与等级，以及当前构筑的完整配方进度。配方齐全与实际获得进化分别显示。手机横屏采用简短摘要和独立详情页，三张卡、详情、构筑入口及重抽同屏；详情不会消费强化，返回后恢复原按钮焦点。

PALISADE 不再冲刺，完整双臂阶段沿用有缺口的弹墙；双臂破坏后改为两组锁定朝向的扇形弹幕，中央保留通路，并在普通／困难模式分别静止收招 1.6／1.3 秒。冲刺类精英移动后静止 1.4／1.2 秒，冲刺与弹幕交替；大型波内精英每两轮弹幕后短距离侧移。ECHO 每套只冲一次，落地静止 1.4／1.2 秒再出弹幕和激光，套尾静止 1.5／1.2 秒。REPRISE 移动后静止 1.5／1.2 秒。收招中的大型敌人不会被普通敌人的分离力推走。
