## 性能证据

旧固定压力场景：180 普通敌人＋70 地雷＋1200 子弹＋900 装饰粒子，1080p 中画质，3 秒预热＋30 秒采样；平均 179.6 FPS，P95 5.7 ms、P99 5.7 ms，无浏览器错误，场景数量准确保持。见 [固定压力数据](performance-v6.0.0.json)。

新增真实浏览器测试保留生产入口 SHA-256、符卡扫描报告 SHA-256 及其源文件哈希：见 [构筑与高密度符卡数据](performance-builds-v6.0.0.json)。每项 3 秒预热；构筑场景各采样 30 秒墙钟时间，选出的符卡采样 45 秒，模拟推进分别约 30／30／45 秒。前两例使用真实 DOM 射击、移动、冲刺与强化选择，未额外调用模拟步进。符卡例保持诊断无敌和站定，无我方弹，首领生命始终不变；实际普通难度经断言确认。

| 场景 | P95 / P99 | 采样峰值 |
|---|---|---|
| 全 36 种 V 层＋18 进化、困难后期编队 | 5.7 / 5.7 ms | 90 敌人、75 敌弹、103 我弹、22 模块场 |

新增场景资源峰值来自每 100ms 采样，不代表逐帧最大值。最高密度是下述明确条件下的扫描结果，不宣称涵盖任意走位与时长。玩家无敌、练习构筑和自动瞄准仅验证负载与稳定性，不能代替真人通关时长、可达路线或核显实测。三例均无浏览器错误，预算断言通过；原固定压力场景仍每秒采样资源。

## 符卡负载扫描补充

`node scripts/scan-spell-density-v6.mjs` 只读转译生产模拟，独立扫描十二张卡×两档难度，各 45 秒、每 100ms 记录在场敌弹、危险区域、攻击预约与首领预告。详见 [完整扫描与源码哈希](spell-density-v6.0.0.json)。玩家在真实竞技场入场点站定，诊断无敌、Lv1，无子机、模块、射击、炸弹或冲刺；首领动作和节点照常运行。无尽练习遭遇隔离普通战役的保底子机奖励，符卡本身没有改写。

这个固定输入下，在场敌弹采样最高为普通 LACUNA 第一张「断层·噤声切片」：240 枚，出现于 11.1 秒。困难 MAFUYU 第六张最高 218 枚；困难 LACUNA 第一张 203 枚。困难弹速更高，在场累积量不必比普通高；此指标不等于难度排序。

`benchmark-v6.mjs` 已读取扫描结果并完成 45 秒 GPU 测试；每例回到菜单设置对应难度并断言实际难度。扫描选卡例清除练习自带子机、设置 Lv1，要求无我方弹且首领生命不变，避免“没有左键”时自动子机和特殊弹仍在攻击。资源采样缩短至 100ms。GPU 同样采样到 240 枚敌弹，与 CPU 结果一致；这不把单种位置轨迹的采样最大值当作所有走位下的数学上限。
