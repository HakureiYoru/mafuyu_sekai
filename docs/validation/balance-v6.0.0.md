# v6.0.0 成长与战役平衡记录

本记录使用真实生产模拟、真实候选与掉落；没有预装构筑、补经验或调整敌人生命。它用于检查成长曲线、输出和流程时长。输入控制器具有精确瞄准与几何预测，不能据此声称普通玩家的通关率或主观难度已验收。

## 复现与数据边界

- `node scripts/balance-v6.mjs`：种子 60001–60010 × 主炮／子机／机动／混合偏好 × 普通／困难，共 80 局正常生命战役。
- 60 Hz 生产模拟，从 Lv1、5 HP、3 炸弹开局；每 100 ms 产生一次输入，已显示的承诺动作有 200 ms 识别延迟，弹道和路线都按 150 ms 采样。
- 只在真实候选中选择；偏好 III／V 形态节点及对应分支，不假设能获得指定模块。升级队列和首领奖励均通过生产 `chooseUpgrade` 完成。
- 最长 1200 秒；死亡、超时与通关分别保留。正常生命不写入无敌、不补生命，也不修改敌方 HP。
- 文件记录所有加载模拟源码及脚本的 SHA-256，结束再次比较；`status=stale-sources` 的中途开发报告仅作诊断，不是最终验收。
- CPU 执行耗时不是浏览器帧时间；独显性能与核显待实测目标见独立性能记录。

## 统计口径

`collectedXp` 只统计真正收取的 XP 球。首领直接奖励、炸弹／子机溢出和选卡 XP 不混入此列；入口等级、当前 XP 和模块层数则包含所有实际收益。

伤害只取生产 `hit` 事件中带 `enemyType` 的实际扣血，已扣除护盾、弱点倍率和过量伤害。打断用的辅助弱点命中事件不重复计入 DPS。新模块按 `moduleId` 分列，原有攻击按 `damageSource` 分列。精英伤害从出生后最终 `role` 判定，不能仅使用构造瞬间的角色值。

每 10 秒记录敌弹、危险区、友方弹与模块实体、HP、炸弹、冲刺库存、等级及总层数。普通怪分母仅含 `role=mob` 且确由伤害击杀的实体；段落清场、地雷、碎核、首领部件不会混入。

- **首攻率**：击杀前已观察到真实发弹、激活危险区、冲刺／激光动作或到达接触范围的比例。它是保守口径；修复者仅治疗不会算攻击，未逐个归因的地雷也不伪称真实命中威胁。
- **释放率**：实际首攻或 `release` 提示；布雷怪到达释放阶段可能仍受间距和容量检查，因此与真实发弹明确分开。修复成功另外记录。
- **可见 TTK**：首次进入逻辑画面到伤害死亡；正常清场移除单独标记并剔除。
- **入场超时率**：`ThreatDirector.onDeferredCancel` 真正回调次数／（获准次数＋超时次数）。逐帧重试的 `false` 不算新的取消。
- **预约取消率**：10 秒内有剩余载荷的 `AttackBudget` 显式取消／（完整消费＋取消＋带载荷到期）。活源取消、死亡／缺失源取消、清场重置、带剩余载荷到期分别记录。保守预留未用满也可到期，不能直接解释为漏招。
- **承诺释放拒绝**：已有对应预留的 `take` 返回失败次数，单独监测技术容量是否截掉已预告攻击。

## 模块实现边界

36 模块提供 I／III／V 的形态节点，18 个组合进化补充独立行为；旧 24 模块 I／II 保留原数值。V 后伤害按 `1 + 0.12 × log2(max(1, 层数−4))` 继续增加，冷却趋近 V 基准的 65%，实体数量不再增加，范围逐步趋近 V 的 125%。成长选项和层数不封顶，视觉实体与碰撞工作量有界。

新模块控制器最多 192 个有限寿命实例；星标 2、音符 6、减速尾迹 2、纸偶 2、晶毯 3。静电花园为让连续两轮音符形成可见连线，将该进化的音符有效期设为 4.5 秒；普通音符仍为 3 秒，场上总数仍最多 6。

所有次生伤害不递归触发模块。新模块伤害生成时只应用一次共鸣倍率；共鸣最初四级每级 5% 保留，其后每 600 XP 仍选卡，不继续增加这项被动倍率。升阶不恢复已消耗的复苏，也不重置冷却。主动实例在遭遇清理时回收，整局消耗和冷却保留。
