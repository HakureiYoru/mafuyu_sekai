# v5.1.0 双人气泡通讯验证

日期：2026-09-17。Windows、Node.js 22.17、Chromium WebGL D3D11、RTX 3060 Laptop。

本次只变更通讯内容、HUD 和装饰素材。没有调整战斗数值或模拟实体，不将旧版平衡、30 分钟续航结果称作本次实测；核显性能目标仍需对应设备测试。

## 资产与画面

八张新绘透明 WebP 共 488,016 字节，原始图透明通道检查通过；浏览器解码联系图逐张查看，人物全身、表情、服装一致且无矩形背景。见 [联系图](v5.1.0-contact-sheet.png) 与 [来源／提示词记录](../asset-sources-v5.1.md)。

## 自动验证

`npm run check` 已通过：全项目类型、lint、25 个测试文件／485 项单元测试（其中通讯 30 项）、五张原 PNG、八份道具和八张通讯素材哈希，以及生产构建。原 PNG 全部与 v2 基线一致。

新增 `tests/comms.spec.ts` 的 7 项综合浏览器测试通过，覆盖六种窗口、两句关系、逐字不重播动作、暂停／失焦／真实拾取升级冻结、真实伤害打断、首领入场、终局双句、重开、收起、低画质／减弱动态和图片加载失败回退。

全套 `npx playwright test` 43 项通过（2.7 分钟）。随后只修正气泡断行规则：重新生产构建并通过六窗口定向回归（16.9 秒）；另以浏览器逐字测量全部 276 句，正常气泡最多两行、小气泡最多三行，没有仅含标点的孤行。

## 浏览器视觉记录

人工查看真实 Chromium 截图，人物透明边界正确、表情一致，没有对战场矩形产生遮挡。六尺寸为 1280×720、1920×1080、2560×1440、2560×1080、807×519 与 807×900；最后一种侧边无余量，使用底栏双头像，六槽仍完整。

代表截图：[1280×720](v5.1.0-battle-720.png)、[807×519](v5.1.0-battle-small.png)、[807×900](v5.1.0-battle-tall.png)。布局测试只证明 UI 和交互行为；截图中的帧率数字不作为独立性能基准。
