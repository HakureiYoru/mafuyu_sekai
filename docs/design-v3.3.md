# v3.3：两档难度与第三波 ECHO

研究与实现核对日期：2026-09-11。本文记录当前实现的首版参数，核对入口为 `src/game/difficulty.ts`、`config.ts`、`enemy-ai.ts`、`boss-ai.ts`、`miniboss-ai.ts`、`simulation.ts` 与 `runtime.ts`。下列数值是本项目的设计选择及代码推导，不是参考游戏公开的原始数值，也不是已经得到真人平衡验收的最优解。此前 `research-v3.2.md` 中的候选方案保留为研究历史，当前实际行为以本文和代码为准。

## 两档模式的实际数值

难度只在菜单中选择，开始后固定；暂停、重开和剧情通关后进入无尽都会保留选择。普通与困难分别保存本地最高分。玩家基础能力保持一致：5 点生命、普通移速 300、精确射击移速 180、普弹伤害 2、冲刺速度 1080 / 持续 0.18 秒 / 冷却 2.6 秒，受击保护为 40/60 秒。

| 项目 | 普通 | 困难 |
| --- | ---: | ---: |
| 普通敌人生命倍率 | 1 | 1.5 |
| MAFUYU / ECHO 生命倍率 | 1 | 1.35 |
| 普通移动倍率，包括 ECHO 接近移动 | 1 | 1.3 |
| 敌方子弹速度倍率 | 1 | 1.28 |
| 子弹、接触、地雷、地面爆破、敌方激光的单次伤害 | 1 | 2 |
| 常规刷怪间隔倍率 | 1 | 0.78 |
| 高威胁攻击同时占用名额 | 3 | 4 |
| 两次新连招提交的最小间隔 | 0.28 秒 | 0.18 秒 |
| 击杀积分附加倍率 | 1 | 1.5 |

普通移动倍率不再重复乘到显式配置的冲刺速度上；MAFUYU 的定位移动也使用独立速度 110 / 150。敌方发弹速度统一由 `simulation.enemyShoot()` 乘一次倍率，例如狙击弹从 600 变为 768，扫射弹从 270 变为 345.6。持续伤害仍受受击保护限制，不能解释为每帧扣 2 点生命。没有恢复时，5 点生命分别可承受 4 次 / 2 次命中，第 5 次 / 第 3 次致命。

第一波基础生命如下，数值在难度与波次倍率计算完成后统一向上取整；地雷保持 1 HP：

| 类型 | 普通 HP | 困难 HP |
| --- | ---: | ---: |
| basic | 6 | 9 |
| dasher | 18 | 27 |
| sniper | 28 | 42 |
| sprayer | 60 | 90 |
| minelayer | 36 | 54 |
| ECHO（剧情固定生命） | 600 | 810 |
| MAFUYU（剧情固定生命） | 1800 | 2430 |

以 Lv1 单颗普弹全部命中 basic 为例，击杀需求是 `ceil(6/2)=3` 发与 `ceil(9/2)=5` 发；Lv1 每秒 6 次发射，首发到末发约为 0.333 / 0.667 秒，未计弹道飞行和实际瞄准。这说明生命增加 50% 在整数命中次数上可能产生更大的体感变化。子机、贯穿炮、多弹命中和突进蓄力易伤不包含在这个简化比较中。

常规刷怪间隔为第 1–5 波的 0.95 / 0.85 / 0.78 / 0.72 / 0.65 秒，再乘难度系数。困难的稳态频率是 `1/0.78≈1.282` 倍，即提高约 28.2%；首波间隔为 0.741 秒。敌人数上限、出生预告、特殊遭遇仍会限制实际生成量。困难还把兵种解锁提前一波，并改变精英抽样：首波普通全为 basic，困难约为 40% basic / 60% dasher；后续布雷与狙击被替换回 basic 的概率从 70% 降到 35%。因此不能把困难的整体压力归结为单一的生命倍率。

击杀积分实际公式是 `round(敌人最终最大生命 × 10 × 难度积分倍率)`，地雷不计分。首波 basic 为 60 / 135 分，ECHO 为 6000 / 12150 分，MAFUYU 为 18000 / 36450 分；困难最终积分不是简单比普通高 50%。

当前剧情为 5 个 40 秒普通波，合计 200 秒，再进入最终 Boss 遭遇。总通关时间还受输出、走位与 Boss 定位影响，不能仅由这些计时器推断已经达到某个真人通关时长。无尽保留额外的波次生命、体型和移动成长；本文的生命表仅针对剧情，不应直接套用于后期无尽。

## 普通敌人的战术差异

| 敌人 | 普通 | 困难 |
| --- | --- | --- |
| basic | 追击、有限提前量、侧翼三种角色；提前量最多 110，时间 0.35 秒 | 四种角色加入两翼截击；只读已观察到的移动，提前量最多 160，时间 0.5 秒 |
| dasher | 预告 0.85 秒，最后 0.45 秒锁向；500 × 0.62 秒冲刺 | 预告 0.6 秒，最后 0.35 秒锁向；620 × 0.55 秒冲刺；恢复 0.65 秒 |
| sniper | 1.1 秒预告，最后 0.55 秒锁向；2 发、间隔 0.18 秒 | 0.8 秒预告，最后 0.45 秒锁向；3 发、间隔 0.14 秒；保持更远距离 |
| sprayer | 0.8 秒预告；1.3 rad 扇区内依次扫出 9 发 | 0.6 秒预告；1.5 rad 扇区内从两端交替向中间发出 13 发，锁定后不重瞄 |
| minelayer | 0.65 秒预告后放置 2 枚地雷 | 0.5 秒预告后尝试三角形放置 3 枚；每个落点仍检查玩家距离及墙内地雷间距 |

地雷两档均有 1.1 秒无伤害起爆准备。出生、布雷与攻击名额受模拟统一约束；强敌等待名额时不会提前消耗预告时间。

## 第三波 ECHO：移动中的中场考验

剧情第三波经过 8 秒时安排一次 ECHO 出场，先显示 1.6 秒出生预告，因此通常在该波约 9.6 秒实际生成。出生预告在固定步内计时，边界有一个模拟步量级的量化差异。若敌人容量已满，保留预约并延后重试。无尽不会再次按这个第三波规则安排 ECHO。

ECHO 出场、存活和击杀均不暂停普通刷怪，不清除已有敌人或子弹，也不暂停波次计时。它可以存活到后续普通波。最终 MAFUYU 出场仍沿用独立 Boss 遭遇的清场规则。

ECHO 的连招是“锁定冲刺路线 → 冲刺 → 停稳 → 锁向短激光 → 恢复”。接近距离不足 260、超过 850 或自身在画面外时，先重新找位置。冲刺终点优先取玩家已采样位置的侧翼，检查墙内路径和身体间距；实际路程可短于最大冲刺距离。警告后玩家改变位置，不会改变这一段冲刺的终点或激光方向。

| ECHO 参数 | 普通 | 困难 |
| --- | --- | --- |
| 接近速度 / 半径 | 155 / 64 | 201.5 / 64 |
| 第一阶段冲刺预告 | 0.75 秒 | 0.5 秒 |
| 第二阶段冲刺预告 | 0.65 秒，单次 | 每次 0.45 秒，双冲刺 |
| 冲刺速度 / 时长 / 最大路程 | 760 / 0.42 秒 / 319.2 | 880 / 0.38 秒 / 334.4 |
| 每段冲刺后的停稳 | 0.25 秒 | 0.25 秒 |
| 激光锁向预告，阶段 1 / 2 | 0.9 / 0.85 秒 | 0.65 / 0.65 秒 |
| 激光宽 / 长 / 持续 | 60 / 1600 / 0.32 秒 | 72 / 1800 / 0.4 秒 |
| 恢复，阶段 1 / 2 | 1.2 / 1 秒 | 1 / 0.9 秒 |

生命降到 45% 后进入第二阶段，先让已承诺的连招完成，再在追击或恢复状态中给予 0.85 秒阶段过渡。困难第二段冲刺另有完整锁向预告。整套连招只占一个攻击名额，后续冲刺与激光不二次抢占；玩家离开有效画面或距离后，后续进攻取消并进入恢复。

击杀奖励在场地上生成：普通 180 XP、1 点生命、1 份弹药、1 份冷却剂、1 个子机模块；困难为 240 XP、2 点生命，其余相同。弹药补满到 120，冷却剂清空热量与过热锁；子机最多 3 架，满额后的模块折为 30 XP。奖励需要实际拾取，不是在击杀时直接恢复玩家，也不以击杀 ECHO 作为剧情通关条件。

## MAFUYU：更短预告与有限组合

三个血量阶段仍为 65% 以上、30%–65%、30% 以下；跨阶段有 1.6 秒过渡，清理敌方子弹和 Boss 地面危险。首招开场等待为 1.8 / 1.1 秒；恢复为 1.15 / 0.65 秒，阶段之间的普通呼吸时间分别为 1.6/1.3/1 与 0.8/0.65/0.5 秒。

| 攻击 | 普通 | 困难 |
| --- | --- | --- |
| 扇形连射，各阶段“每轮弹数 × 轮数” | 3×1、5×2、5×3 | 5×2、7×3、9×3；预告 0.95/0.9/0.85 秒 |
| 缺口环弹，各阶段“候选弹位数 × 轮数” | 24×1、28×2、32×3；缺口 1.3/1.25/1.2 rad | 30×2、34×3、38×4；缺口 1.05/0.95/0.9 rad；奇偶轮错开半个弹位，缺口中心固定；实际弹数扣除缺口内弹位 |
| 地面爆破 | 同时标出中心与两侧 3 点；预告 1.25 秒起，每点间隔 0.5 秒，半径 100 | 同时标出十字 5 点；预告为 0.85/1.09/1.33/1.57/1.81 秒，半径 85 |
| 扫动激光 | 锁向预告 2.2 秒；持续 3.2 秒；角速度 0.38 rad/s；冷却 14 秒 | 锁向预告 1.25 秒；持续 2.6 秒；角速度 0.42 rad/s；冷却 9 秒 |

困难 Boss 的每隔一轮选招会在提交时看当前场景：距离小于 390 优先环弹，否则玩家已观察速度至少 140 时选地面爆破，其余选扇形连射；另一轮沿阶段既定序列执行，冷却完成的激光优先。第二、三阶段环弹可组合两处提前标明的侧翼爆破，中心缺口不跟随玩家改变。没有无限叠加任意技能的组合器。

Boss 的大招状态独占进攻：普通强敌停止发起/执行攻击，追击和恢复期才恢复增援机会。激光预告开始前清敌弹和 Boss 地面危险，避免旧弹直接占住当前扫射路线；这不是对任意敌人身体与地雷布局的全局可达性证明。

## 几何与验证边界

ECHO 固定激光的最小纯垂直侧移量为“半宽 + 玩家半径”：普通 48，困难 54。普通移速 300 时分别约需 0.16 / 0.18 秒；困难预告扣除 0.2 秒反应后仍有 0.45 秒，理论路程为 135。实际测试把身体碰撞、世界边界和整套冲刺也一起检查，在两档、两阶段、中心与四角的 20 个独立场景中，找到 0.2 秒反应后普通移动不超过 135 的零伤路线。

MAFUYU 激光宽度两档均为 96，身体半径计入后需至少 66 的光束中心线距离。普通从玩家初始方位侧偏 0.65 rad 起扫，最后到另一侧 0.471 rad；困难侧偏 0.58 rad，最终到另一侧 0.449 rad。开火后分别先驻留 0.25 / 0.15 秒再扫动，驻留期间光束已经可以造成伤害。

一个已测试的困难直线路径是在距离 700 处，向扫动方向侧移 1.4 秒：`300×(1.25+0.15)=420`，随后停下；到最终光束中心线的距离约 `sqrt(700²+420²)×sin(atan(420/700)−0.449)=74.5`，大于判定要求 66。它利用了侧偏起手和开火驻留，且从预告出现就开始移动。这个例子不能推出“距离 700 处任意反应延迟、任意方向都安全”。困难模式测试另有定时冲刺路线，玩家可用冲刺取得更大余量。

本轮验证包括 ECHO 的 38 项测试，以及难度倍率、伤害、波中出生、容量重试、奖励、难度保持和攻击名额的实际模拟集成检查。跨帧率测试使用累计毫秒时间戳推进真实 12 秒，并断言阶段变化与攻击事件确实发生，再比较 30/60/120/144 Hz 的结果；它不是只比较未推进的初始状态。

这些测试证明特定可复现场景的行为、资源归属与走位可行性，不代表真人完成率、学习成本或所有随机组合已经平衡。后续试玩应分别记录两档通关/失败时间、ECHO 击杀率、初见受伤来源、恢复资源是否真正拾取，以及玩家能否说清下一次躲法。无敌自动化与压力测试用于稳定性和性能，不能替代这些平衡反馈。
