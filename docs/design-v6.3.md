# v6.3 武装特化与精英分工

本轮不新增主动按键、原始素材、模块数量或战役长度；强化现有构筑，并给 ECHO 之后加入三种战术敌人。

## 武装

- 主炮原输出保留。贯通与校准同时装配、慢移校准完成后，每六轮追加整轮基础主炮合计伤害 75% 的高速五穿重针。追加来源为次生，不触发连锁或基础命中计数。
- 翼炮 I／II 每侧基础总伤害从 1／1.5 调至 2／3；乘 `1 + 0.25 × (Lv−1)`。I／III／V 每侧 1／2／3 发均分伤害，后续层数不增加实体。普通移动展开、校准慢移时汇聚于前方 300；贯通传递一半额外穿透，翼炮最多命中三敌。
- 子机基础弹乘 `1 + 0.2 × (Lv−1)`，再乘子机分支种类加成（每种 10%，最多五种）。共振集火 I／II 基础伤害 18／24，三角围攻总基础伤害 36；同样按武器等级成长。
- 焦点灯 I／III／V 每束基础伤害 10／14／18、长度 680／740／800、宽度 24／30／36。焦点灯、音符、刀弧及连线伤害按武器等级成长；护刃原伤害不变。
- 共振＋追迹使重弹有限追踪 1.2 秒；焦点灯＋束流棱台在每轮第一束开始时让其他最多两台子机追加半伤短束。衍生束无再衍生回调，每束只结算一次。
- 使用独立翼炮炮口、加长冷色轨迹、重针束芯和子机蓄光环。选卡预览同步显示四／六翼弹形态，构筑详情说明五组即时联动。

## ECHO 后的新敌人

| 名称 | 推进时间 | 基础 HP | 机制与反制 |
| --- | --- | --- | --- |
| 裂隙追猎 | 100 秒 | 30 | 绕侧保持距离，锁定短冲路线，落地后另行预警再向旧位置扇射；躲开路线后反击 |
| 折镜执灯 | 125 秒 | 40 | 一次部署两枚可拆镜片，预告与短激光共用几何；拆镜片取消对应未发激光并暴露本体，全部拆除改扇射，不再生 |
| 噤声指挥 | 165 秒 | 34 | 自身与最多两只邻近普通怪组成三个锁定射点，依次齐射；击杀中继单位取消该点尚未释放的攻击 |

按既有战术怪进度与难度倍率取出生生命，纳入战术总上限、强攻击名额及空间威胁编排；每种普通／困难最多 1／2 只。普通／困难起手 1.1／0.9 秒，追猎落地扇射另给 0.85／0.7 秒。激光宽 36、持续 0.32 秒，镜片普通 HP18。出招前预约弹池及危险区容量，警告后的攻击不会被我方连锁挤掉。部件无经验、无季终事件。

## 十种精英的不同解法

| 精英 | 主要区别 |
| --- | --- |
| 跃袭标兵 | 直冲与扇射交替，骗过落点后绕侧 |
| 追声快手 | 侧前短冲与两批错拍针束 |
| 噤声门卫 | 可拆发射臂、分批门阵，两轮后侧移 |
| 横梁巡查 | 不冲刺；单激光与两条平行激光交替，双轨间净宽 140 |
| 折光信使 | 侧移后发一次弯折弹，另招三批针束；弯折弹不原路返回 |
| 旧影记录员 | 不冲刺；三次旧位置延爆，下一招沿实际采样点连接短激光 |
| 回声猎手 | 去程、间隔扇射与身体原路回冲，回程不重瞄 |
| 停拍投手 | 不冲刺；两批停驻折返刀刃与三批针束交替 |
| 裂核执刑者 | 不冲刺；部署可拆侧翼碎核，打断散射 |
| 环阵监察 | 不冲刺；外放／内收弹环带换位开口，不叠入身体冲撞 |

本轮保持精英及主首领血量不变，保留 v6.2 的符卡通路与动作节奏。
