# v5.0.1 文案：Wonderhoy 串门中

历史记录：本版的“礼貌送客／轻松拌嘴”方向已被用户明确纠正。后续编辑遵循 [v5.0.2 文案规范](copy-v5.0.2.md)，采用阴暗黑化真冬与简单大喊 Wonderhoy 的笑梦。

## 场景与口吻

笑梦把空白 SEKAI 当临时游乐场，真冬学姐礼貌地用弹幕送客。以凤笑梦的行动力、杂技、乐园和突发点子，碰上朝比奈真冬的优等生外表、平静措辞、作词和水族箱，形成轻松的反差。偶尔让笑梦被学姐的笑容吓到，但很快又去想下一个点子。

参考角色官方介绍：[凤笑梦](https://pjsekai.sega.jp/character/unite04/emu/index.html)、[朝比奈真冬](https://pjsekai.sega.jp/character/unite05/mafuyu/index.html)。本次 217 条台词与道具彩蛋均为游戏原创同人文案，不作为官方原句。避免让真冬只剩绝望独白或恶意威胁，避免用家庭创伤充当笑点。

## 覆盖与层级

- 菜单只多一句“笑梦来送快乐，学姐来送弹幕。”，保留简洁操作说明；页面标题和分享描述同步定位。
- 加载、设置、暂停、失败、通关、更新日志换成演出与串门语气。按钮仍用“开始游戏”“继续游戏”等明确动作。
- 五段流程分别为“空白场地试营业”“学姐好像看过来了”“笑容压力测试”“再来一场就收工”“25时禁止喧哗”。
- 五首领保留英文代号，追加“礼貌追客”“闭园闸机”“微笑送客”“谢绝返场”“25时闭园广播”。十二张符卡保留招式形象，如“排队·请走这一边”“水族箱·请勿敲玻璃”。
- 24 模块、6 进化、3 资源补给均提供独立 `flavor`。功能名称与精确数值说明保持原样，风味文字不承担规则解释。
- 道具提示采用“彩蛋名 · 用途”，如“小笑梦 · 支援子机”；地雷、敌弹、激光、过热、冲刺、数值浮字与存档错误继续直说。
- 通讯使用两行，展示中文角色名；新台词正确映射笑梦／真冬头像。首领入场、符卡击破及三位小首领战斗独立路由，部件不会冒充角色退场；满级台词只在满级触发。
