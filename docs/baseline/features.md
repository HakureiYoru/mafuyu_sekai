# v2 → v3 功能迁移核对

基线：Git `bd37056`。五张 PNG 的路径和 SHA-256 见 `assets.sha256.json`；音频继续使用原 `public/sound/shot.wav` 与 `public/assets/music/bg.mp3`。

| 原功能 | v3 实现与核对位置 |
| --- | --- |
| WASD、鼠标射击、R/右键冲刺、空格炸弹 | `input.ts`、`simulation.ts`；额外支持 Esc 暂停和失焦清空输入 |
| 普通、多弹、追踪、穿透与冲刺强化射击 | `config.ts` 集中武器成长，`simulation.test.ts` 检查解锁、发射时伤害与穿透去重 |
| 普通、突进、狙击、扫射、布雷怪与地雷 | `ENEMIES`、独立 AI 分支；原头像与原色保留，外围形状/提示区分类型 |
| Boss 弹幕、激光、小怪召唤 | 独立 Boss 阶段；共享激光几何；预警、锁向、冷却、弹幕切换间隙 |
| 五波剧情与无尽挑战 | 每波 60 秒；首个 Boss 击杀后可继续无尽，后续每十波进入 Boss |
| 经验、血包、炸弹、弹药、冷却液、微型爆破、黑洞 | 所有 7 种掉落保留；就近聚合，按实际领取量扣除份数 |
| 经验成长、受伤掉经验和降级 | 保留溢出经验，Lv1–10 与掉级事件；升级需求按 v3 首版配置 |
| 分数与失败、重开、通关 | React 流程状态与独立模拟状态衔接，本地最高分 |
| 角色对话 | 原 21 组文本完整迁入 `src/game/data/dialogue.json`；事件触发，暂停冻结，通讯可收起 |
| 背景音乐、射击音 | 原音频通过 Web Audio 缓存、混音与声部限制播放 |
| 更新日志 | 保留旧记录，唯一 JSON 数据源，菜单显示 `v3.0.0` 并提供完整弹窗 |
| HTML / Next / Electron 多入口 | 静态浏览器版本统一入口；`/dx.html` 兼容跳转；Electron 本轮不交付 |

视觉基线截图仅用于对照布局。旧版开局性能测量使用软件渲染，与新版独显压力测量的设备路径、分辨率、负载不同，不能据此计算提升倍数。
